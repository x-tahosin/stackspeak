# StackSpeak

> **Calm, voice-guided pair-debugger and visual AST explainer for developers with dyslexia and ADHD.**  
> Built for the DEV.to Hacktoberfest Weekend Challenge: *Build for a Friend*. Dedicated to Marcus T.

---

## The Story: Built for Marcus

Marcus is a brilliant systems thinker and community mentor who freezes when nested terminal stacktraces explode across his screen. Severe phonological dyslexia causes jumping syntax brackets and dense compiler dumps to trigger cognitive overload.

Traditional AI chatbots often worsen this anxiety by dumping even longer walls of text.

**StackSpeak** replaces compiler chaos with:
1. **Auditory Pair-Programming:** Empathetic spoken diagnosis powered by ElevenLabs Neural Audio clones.
2. **Visual AST Branching:** Clean 3-node Abstract Syntax Tree diagrams showing safe paths vs error states.
3. **Open-Weight Causal Core:** Local, private causal reasoning powered by Gemma 2 with zero cloud telemetry.
4. **Accessible Typography:** OpenDyslexic-inspired high-contrast UI mode tailored for visual comfort.

---

## Core Capabilities

- **3-Column Debugger Workspace:**
  - Real-time compiler stacktrace parsing (TypeScript, Node.js/Express, Rust, React 19).
  - Dynamic visual syntax branch graphs highlighting exact crash lines.
  - Interactive voice player with animated frequency bin equalizers and conversational transcripts.
- **Deep Incident Diagnostics:**
  - Visual Error Flow tracing requests from ingress to failure origin.
  - Root cause causal analysis verified by Gemma 2.
  - One-click safe fix application with instant visual verification.
- **Privacy First (Zero Telemetry):**
  - Offline local AST processing with open weights.
  - No secret code leaks or third-party telemetry.

## Quick Start

### Prerequisites
- Node.js 18+
- npm or pnpm

### Local Development
```bash
# Clone the repository
git clone https://github.com/x-tahosin/stackspeak.git
cd stackspeak

# Install dependencies
npm install

# Start Vite development server
npm run dev

# Or build and preview production bundle
npm run build
npm run preview
```

Open `http://localhost:3001` in your browser.
